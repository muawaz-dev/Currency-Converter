#  Currency Converter App

A modern, responsive **Currency Converter** built with **React.js**, **Tailwind CSS**, and **HTML**.  
This app allows users to convert between multiple **world currencies** and popular **cryptocurrencies** with a clean and intuitive interface.

---

##  Features
-  Convert between fiat currencies (USD, EUR, PKR, INR, etc.)
-  Supports major cryptocurrencies (BTC, ETH, etc.)
-  Fully responsive design using Tailwind CSS
-  Fast and interactive UI powered by React.js
-  **Home Page**: Perform conversions with real‑time rates
-  **About Page**: Learn more about the app and its purpose

---

##  Tech Stack
- **Frontend:** React.js, HTML5, Tailwind CSS
- **API:** ("https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies{country_code}.json")
- **Styling:** Tailwind CSS for modern, responsive design
